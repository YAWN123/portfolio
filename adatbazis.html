Adatbáziskezelés

Feladat Leírása

Ez az Adatbázis feladat a Mikrovezérlés-es feladathoz lett készítve, MySQL Workbench nevezetű programban.(előző oldal,Roulette)

A programban használt műveletek

  • CREATE - Valamilyen féle tároló készítése(TABLE, DATABASE)
  • INSERT - Meglévő tárolóba egy változó beszúrása
  • SELECT - TABLE-ből a változó kiválasztása
  • GROUP BY - Változók Összegzése
  • ORDER BY - Eredmények Rendezése

Feladat Fő része


            CREATE DATABASE roulette;
            USE roulette;

            CREATE TABLE jatekos (
                jatekos_id INT AUTO_INCREMENT PRIMARY KEY,
                nev VARCHAR(100) NOT NULL,
                szemelyi_szam VARCHAR(20) UNIQUE,
                regisztracio DATE
            );

            CREATE TABLE jatek (
                jatek_id INT AUTO_INCREMENT PRIMARY KEY,
                datum DATETIME,
                nyertes_szam INT,
                szin VARCHAR(10)
            );

            CREATE TABLE tet (
                tet_id INT AUTO_INCREMENT PRIMARY KEY,
                jatekos_id INT,
                jatek_id INT,
                tet_tipus VARCHAR(50),
                osszeg INT,
                nyeremeny INT,

                FOREIGN KEY (jatekos_id) REFERENCES jatekos(jatekos_id),
                FOREIGN KEY (jatek_id) REFERENCES jatek(jatek_id)
            );

Profit Lekérdezése


            SELECT 
                j.nev,
                SUM(t.nyeremeny - t.osszeg) AS profit
            FROM tet t
            JOIN jatekos j ON j.jatekos_id = t.jatekos_id
            GROUP BY j.nev;

Legnagyobb Nyeremény Lekérdezése

            SELECT *
            FROM tet
            ORDER BY nyeremeny DESC
            LIMIT 1;
